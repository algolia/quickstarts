# Algolia quickstarts

Collection of runnable Algolia quickstarts.
Each folder is a standalone example app with its own dependencies,
setup steps, and README.

| ---------------------------------------------------------------------- | ------------------------------------- | -------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| [`product-search-react-typescript`](./product-search-react-typescript) | React InstantSearch, TypeScript       | Product search | [Build your first search experience](https://www.algolia.com/doc/guides/get-started/quickstart)                                          |
| [`product-search-react-supabase`](./product-search-react-supabase)     | React InstantSearch, Supabase, Vercel | Product search | [Algolia Supabase connector](https://www.algolia.com/doc/guides/sending-and-managing-data/send-and-update-your-data/connectors/supabase) |
